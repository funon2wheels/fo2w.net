# FO2W.net

Simple static website for **Fun on 2 Wheels**.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload everything in this folder to the root of the repository.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`.
6. After GitHub Pages is live, add your custom domain: `fo2w.net`.

The site is plain HTML/CSS/JavaScript and does not require a build step.
